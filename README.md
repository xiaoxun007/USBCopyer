# StorageService（USBCopyer 高隐藏性定制版）

**插上 U 盘自动按需复制文件。本 fork 在原版 USBCopyer 基础上做了高隐藏性改造，程序名、进程名、输出目录、注册表项、界面文案全部中性化。**

## 本 fork 改动（相对 kenvix/USBCopyer）

1. **程序改名**：程序名 / 进程名 / 窗口标题 / 托盘提示统一改为 `StorageService`（编译产物 `StorageService.exe`）
2. **输出目录改名**：默认复制目录 `USBCopyerData` → `StorageServiceData`，配置目录 `USBCopyerSystem` → `StorageServiceSystem`
3. **默认隐藏启动**：无参数启动即隐藏（无窗口、无托盘图标），仅显式 `/gui` 参数显示界面——与上游默认显示不同
4. **系统风格图标**：Win10 风格蓝色齿轮图标（主图标 + 托盘空闲/工作图标）
5. **元数据中性化**：exe 属性（公司/版权/描述）不再包含原工具名与原作者信息
6. **移除外部链接**：设置界面与捐赠窗口中指向原作者域名/项目页的跳转已移除
7. **CI 编译发布**：GitHub Actions 自动编译 Release 标准版（.NET Framework 4.8，覆盖 Win7+）并打包

原版全部功能保留，详见下文。

## 原版功能

1. 支持设置冲突解决方案
2. 支持选择性复制，包括扩展名黑白名单、磁盘黑白名单。磁盘黑白名单支持序列号
   白名单模式结合版本控制可以方便地备份 U 盘
3. 支持隐藏模式及开机启动
4. **支持设置回调**，可以自己编写代码实现某种高级的、程序没有提供的功能。
   默认提供 **Git 版本控制支持**
5. 支持限制文件大小，防止复制大文件造成延误
6. 支持延迟复制，对"偷"课件类的场景提升用户体验十分有用

程序有两个托盘图标，蓝色表示空闲，红色表示正在复制文件（工作中）。

### 适用场景

1. 获取授课教师的课件
2. 获取插到某台公用电脑上的 U 盘的数据
3. 快捷地备份 U 盘
4. 备份 U 盘的同时进行版本控制

### 如何使用

1. 下载 Release 中的 `StorageService.Release.v*.exe`
2. 运行 `StorageService.exe`（默认隐藏运行，进程可见于任务管理器）
3. 如需打开设置界面：运行 `StorageService.exe /gui`，右击托盘图标可调整参数

#### 命令行

```
StorageService.exe [/hide] [/gui] [/reset]
```

| 参数 | 作用 |
|------|------|
| （无参数） | 隐藏模式启动（默认），无窗口无托盘图标 |
| /hide | 隐藏模式启动，只能通过任务管理器结束进程 |
| /gui | 显示界面（设置窗口/托盘图标），可用来解除隐藏模式 |
| /reset | 恢复默认设置并退出，若失败，返回退出码 1 |

#### 自定义分类规则

可自定义程序为每个复制的存储设备创建分类文件夹的规则，规则使用以下格式表达式表示。

| 符号 | 含义 |
|------|------|
| `"` | 字符部分始末 |
| `@` | 转义 |
| `[` `]` | 内插元素部分始末 |

| 内插元素名 | 指代的值 |
|-|-|
| serial | 磁盘序列号 |
| name | 卷标 |
| letter | 盘符 |
| type | 描述 |
| fs | 文件系统 |

该规则表达式区分大小写。例如不能把 `[name]` 写成 `[Name]`/`[NAME]` 等。
字符部分的优先级最高，除转义外所有包裹在 `"` 内的字符都会被认定为字符部分。

例：规则为 `[letter]"-foo[name]bar-@@-"[name]`，会为每个 U 盘创建以"盘符-foo卷标bar-@-卷标"命名的分类文件夹用于存储从此 U 盘内复制出的文件。

### 常见问题

##### 复制行为造成 U 盘的文件操作卡顿
请设置一个延迟。通常推荐在使用者开始放映幻灯片时开始复制。

##### 使用者在使用该电脑前重启了此电脑
将本程序设为开机启动即可。设置方法：在程序的"设置"中勾选开机启动。

##### 可否复制手机的文件？
若为 MTP/PTP 则无法实现，但如果是以 Mass Storage（大容量存储）模式挂载到电脑上的设备则可以复制。

##### U 盘在操作完成前被拔出
请使用心理学方法防止 U 盘在操作完成前被拔出。

##### 如何防止拷到病毒？
安装杀毒软件，监控 `StorageServiceData` 目录即可。

##### 目标电脑带有还原机制
两种方法：
1. 插上你的 U 盘，然后启动本程序，加入该 U 盘到黑名单，然后设置输出目录到你的 U 盘
2. 用 PCHunter 之类的程序干掉还原程序
